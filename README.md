# Rent Is Due

**Rent Is Due** is a kid-friendly financial literacy adventure game being built for the Coolmath Game Jam 2026.

Players help Zee explore the city, earn money, avoid tricky deals, manage time and energy, and make smart choices before rent is due.

## Core Stack

- Phaser 3
- Vite
- TypeScript
- Browser-playable HTML5 game
- Target resolution: 800x600

## Core Meters

- Money
- Time
- Energy
- Trust
- Rent Goal

## Production Rule

Keep the game small, polished, readable, and kid-friendly. Finish the core playable loop before adding new systems.
